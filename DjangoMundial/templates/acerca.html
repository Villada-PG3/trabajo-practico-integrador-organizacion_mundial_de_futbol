Acerca del Proyecto

Plataforma web desarrollada como proyecto integrador para la materia de Programación. El sistema permite la gestión y exploración dinámica de la historia de los Mundiales de Fútbol, Selecciones Nacionales y Jugadores.

Equipo de Desarrollo

Integrante 1
Módulo: Mundiales

Administración de ediciones del mundial, sedes y campeones.

Integrante 2
Módulo: Selecciones

Gestión de selecciones nacionales y estadísticas por equipo.

Integrante 3
Módulo: Jugadores

Registro y estadísticas individuales de los futbolistas.

Tecnologías Utilizadas

Python 3 Django Framework HTML5 & CSS3 Bootstrap 5 Git & GitHub
